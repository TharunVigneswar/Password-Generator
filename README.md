# Password Generator
This is a pasword generator program which generates random passwords according to the length of password you give.

# How to install
1. Download the .exe file from the github repo.
2. Open file explorer and double click the downloaded pass.exe
3. It will then launch a small window with the password generator program running in it.
4. You can then press the generate password button and press the copy button to copy the generated password.
5. Adjust the length of the password using the slider in the bottom of the screen.

# Resources
**Libraries Used:**
1. Tkinter
2. Secrets
3. String

**How to access code:**
1. Download the the main.py file in the github repo
2. Open it using any code editor like IDLE, VS Code, Pycharm, etc.
